# Roadmap / бэклог

Статус на 2026-09-17. Архитектурный контекст и диаграммы — в [architecture.md](architecture.md).

## Готово и стабильно (не трогать без причины)

- Auth: регистрация, логин, JWT, email-верификация, смена пароля, refresh-токены
- Email outbox pattern — письма доставляются надёжно через фоновый loop даже при недоступном SMTP
- Профили: bio, аватар, ники, подписки, публичный профиль
- Каталог: загрузка, фильтры, поиск, плеер (desktop + mobile), мобильная адаптация
- Покупки: YooKassa checkout → webhook (+ polling-фолбэк) → скачивание WAV
- Лайки, play count, стемы (загрузка), voice tag
- Мониторинг: Prometheus + Loki + Grafana
- Инвайт-коды для закрытой беты (`INVITE_CODES` в `.env`)
- Синхронизация `author_name` при смене ника (RabbitMQ: `username_changed`)

### Задача 9 — модерация обложек, подробности

Обложки теперь публичные стабильные URL с кэшем на Cloudflare edge (см.
[architecture.md](architecture.md#хранение-файлов-и-приватность-контента)) — запрещённый
контент, попавший в обложку, будет отдаваться из кэша даже после удаления бита из БД/MinIO.
TTL кэша уже снижен до суток без `immutable` как временная мера. Для паблик-лонча нужно:

- Модерация при загрузке (ручная очередь или image-moderation API) и/или
- Активный purge через Cloudflare API по URL при удалении/жалобе

Сейчас в проекте нет ни Cloudflare API-токена, ни механизма жалоб. Для закрытой беты (узкий
круг по инвайтам) риск принят.

**Предложенный флоу** (обсуждён 2026-09-17): асинхронная модерация по аналогии с уже
существующим статусом `PREVIEW_PROCESSING` для аудио:

1. Обложка сразу после загрузки получает статус «на модерации» — не отдаётся публично.
2. beat-worker параллельно с обработкой аудио прогоняет её через image-moderation API
   (AWS Rekognition / Google Cloud Vision SafeSearch / Azure Content Moderator, либо
   self-hosted вроде NudeNet).
3. После чистой проверки обложка переключается на публичный кэшируемый URL. При флаге —
   бит остаётся без обложки и уходит в ручную очередь.
4. Жалобы пользователей как второй контур — автомодерация не ловит контекстные вещи вроде
   текста или символов на картинке.

Не блокирует скорость загрузки — она и так асинхронная (тот же паттерн, что уже работает
для конвертации аудио).
